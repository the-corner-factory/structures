# .agents

**Path:** `.agents`\
**Role:** Shared agent resources

## Purpose

Keep reusable resources for coding agents at the project root, alongside the code they help
maintain. This layout applies across frameworks: the resources describe how to work on the project.

## Guidelines

- Commit resources the whole team should share, and update them when project workflows change.
- Use `skills/` for repeatable tasks such as reviewing changes or preparing a release.
- Keep repository-wide instructions in the root `AGENTS.md`; `.agents/` is a separate directory.
- Check which directories your agent tool discovers. A folder alone does not enable an integration.
- Keep credentials, local sessions, and generated output out of shared agent resources.

## Example layout

```text
.agents/
└── skills/
    └── review-changes/
        └── SKILL.md
```
