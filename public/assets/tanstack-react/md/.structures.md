# .structures

**Path:** `.agents/configs/.structures`\
**Role:** Structures skill configuration

## Purpose

Keep the Structures skill's maintained folder template and module-naming rules in `config.json`.
Other skills keep their configuration in their own directories under `.agents/configs/`.

## Guidelines

- Initialize or update the template through `/structures init` or `/structures update folder structure`.
- Preserve saved policy during folder audits and fixes; change it only when a template update is requested.
- Store optional derived website or Gist files in `exports/`; regenerate them from `config.json`.
- Keep the skill's instructions and scripts in its installed skill directory.
