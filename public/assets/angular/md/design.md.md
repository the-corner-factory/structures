# DESIGN.md

**Path:** `DESIGN.md`\
**Role:** Interface design guidance

## Purpose

Describe the product's established visual language and interaction conventions so contributors
can extend its interface consistently.

## Guidelines

- Record the actual typography, colors, spacing, layout patterns, and reusable UI components.
- Point to existing design tokens and component implementations as their sources of truth.
- Describe responsive behavior, keyboard access, accessible labels, focus, and motion preferences.
- Cover relevant loading, empty, error, and disabled states alongside successful interactions.
- Explain deliberate visual or interaction choices and document agreed exceptions.
- Use `PRODUCT.md` for audience and product goals; keep task-specific implementation instructions
  in `AGENTS.md` and its referenced guides.
